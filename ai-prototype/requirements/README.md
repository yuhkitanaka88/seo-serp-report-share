# CodeCamp 法人向けAI研修 要件書ビューア

確定済みの以下2文書を、長文でも読み進めやすいレスポンシブHTMLへ統合した第1成果物です。

1. CodeCampの現行構造を前提としたAI研修サイト設計案
2. カテゴリ・ハブページと研修詳細ページのキーワード設計案

## ファイル

- `index.html` — 要件書本体
- `style.css` — レスポンシブ表示・印刷表示
- `script.js` — ガイドツアー、進捗、検索、絞り込み、比較切替
- `README.md` — 本ファイル

## 起動

ファイルを直接開いても閲覧できます。ローカルサーバーで確認する場合は次を実行します。

```bash
cd codecamp_ai_requirements
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 主な機能

- 読了進捗と現在章のハイライト
- 6ステップのガイドツアー
- 文書内検索（`Command/Ctrl + K`）
- 案A・B・Cの比較表示切替
- キーワードの検索意図・優先度・文字列フィルター
- 詳細原文の折りたたみ表示
- ダークモード
- モバイル用目次ドロワー
- 印刷・PDF保存用スタイル
- 見出しへの直接リンクコピー

## ガイドツアーのスクロール

2026年7月に紹介された Programmatic Scroll Promises の考え方をプログレッシブエンハンスメントとして採用しています。

- `window.scrollTo()`がPromiseを返す環境ではスクロール完了を`await`
- 未対応ブラウザでは`scrollend`とタイマーでフォールバック
- スクロール後に対象セクションを強調表示

## 要件上の確定事項

- 案Aを採用し、`/business/ai-training`を横断ハブとして新設
- 既存研修詳細URLは原則維持
- 4カテゴリページは削除を前提とせず、URL維持のまま動的化を優先
- 通常ファセットは原則非インデックス
- 検索需要と独自内容がある条件のみホワイトリスト方式で静的化
- 総称語、商品・技術語、比較語、属性語で受け皿を分離
